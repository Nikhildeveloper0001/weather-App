# weather-App
  https://weather-web-app-searchanycity.netlify.app/

A simple and user-friendly Weather Application developed using HTML, CSS, and JavaScript. It allows users to search for a city and view its weather information through an intuitive interface.

## ✨ Features

- Search weather by city name.
- Display current temperature.
- Show city name.
- Display humidity information.
- Display wind speed.
- Weather condition icons.
- Loading indicator while retrieving weather information.
- Invalid city name error handling.
- Clean and responsive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API integration

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/Nikhildeveloper0001/weather-App
```

2. Open the project folder in VS Code.
3. Configure the weather API credentials in `script.js`, if required by the implementation.
4. Open `index.html` in your browser.
5. Enter a city name and search for its weather information.

## 🎯 Project Objective

The objective of this project is to understand JavaScript, API integration, asynchronous operations, DOM manipulation, and handling dynamic weather information.
